## Getting Started

Install Node.js 24.4.1 and pnpm 11.9.0, then run `pnpm install --frozen-lockfile` from the
repository root.

## Local Development

The pnpm workspace contains `apps/api`, `apps/web`, and `packages/shared-types`. Runtime development
commands are introduced with their respective implementation tasks.

## Testing

Run the complete local quality gate with `pnpm check`. Individual commands are available as
`pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test`, and
`pnpm licenses:check`.

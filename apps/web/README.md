# SkyGraph Web Application

This deployable unit will contain the React, TypeScript, Vite, Tailwind,
Leaflet, and Framer Motion single-page application deployed to Vercel.

Its frozen organization is feature-first under `src/features`, with shared
design-system, API, WebSocket, hook, and map-adapter concerns under
`src/shared`, and routing/providers/composition under `src/app`.

No frontend application code is introduced during repository initialization.
